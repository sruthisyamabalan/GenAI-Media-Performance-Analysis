# GenAI-Media-Performance-Analysis
## Raw Data Source

**Dataset Name:** GenAI Media Performance Dataset (2026)

**Source:** [Kaggle – GenAI Media Performance Dataset (2026)](https://www.kaggle.com/datasets/algozee/genai-media-performance-dataset-2026)

### Dataset Description
The GenAI Media Performance Dataset (2026) is used to analyze social media content performance across different platforms. It provides data for evaluating content engagement, audience interactions, and performance metrics.

### Data Source
The dataset was obtained from Kaggle and used as the primary data source for this project.

### Data Preparation
The raw dataset was imported into Microsoft Excel for data cleaning and preprocessing. This included checking for missing values, identifying duplicate records, correcting data formats, and preparing the data for analysis.

### Data Analysis and Visualization
The cleaned dataset was imported into Power BI to create interactive dashboards and visualizations. The analysis focuses on understanding social media performance, comparing engagement across platforms, and identifying content performance trends.

### Tools Used
- **Microsoft Excel:** Data cleaning and preprocessing.
- **Microsoft Power BI:** Data visualization, dashboard creation, and performance analysis.

### Project Objective
To analyze social media content performance, identify engagement trends, compare platform performance, and present meaningful insights through interactive Power BI dashboards.
